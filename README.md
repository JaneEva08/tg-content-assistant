# tg-content-assistant

Telegram-бот — ассистент автора канала. Помогает придумывать темы, писать и редактировать посты в стиле конкретного канала и помнит контекст диалога: можно писать «короче», «другой заголовок», «теперь в формате упражнения».

Стиль канала задаётся одним YAML-файлом. В репозитории — пример вымышленного канала по психологии **«Точка опоры»** с этическими правилами (без диагнозов, обещаний и советов по лекарствам).

## Возможности

- диалог с памятью: последние 20 сообщений на пользователя, `/reset` или «очистить контекст»;
- профиль канала → системный промпт: автор, аудитория, тон, темы, форматы, правила, длина поста, кризисная строка;
- смена модели и параметров прямо в боте: `/model`, `/effort`, `/tokens`, `/temp`, `/settings`;
- доступ только по списку Telegram ID — бот тратит ваш баланс API;
- длинные ответы режутся под лимит Telegram, при обрезке по `max_tokens` бот об этом говорит;
- фото, стикеры и голосовые не роняют бота;
- понятные сообщения об ошибках API (таймаут, лимит, неверный ключ, отклонённый параметр);
- логи параметров запросов и расхода токенов — без текстов сообщений и ключей.

## Стек

Python 3.10+, aiogram 3, OpenAI SDK (Chat Completions) — работает с OpenAI и совместимыми сервисами (ProxyAPI, aiprimetech и др.), PyYAML, pytest.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows;  source .venv/bin/activate — Linux/macOS
pip install -r requirements.txt
copy .env.example .env          # cp на Linux/macOS — и заполнить
python bot.py
```

Свой канал: скопируйте `channel.example.yaml` в `channel.yaml` и отредактируйте. `channel.yaml` не попадает в git.

## Команды бота

| Команда | Что делает |
|---|---|
| `/reset`, «очистить контекст» | очищает историю диалога |
| `/settings` | модель, параметры, размер контекста |
| `/model` | выбор модели кнопками (или `/model имя`) |
| `/effort` | reasoning effort: low, medium, high или по умолчанию |
| `/tokens 1000` | лимит ответа |
| `/temp 0.7`, `/temp off` | temperature 0.0–2.0 или по умолчанию модели |

## Скрипты для эксперимента

```bash
python probe_params.py --list        # модели, доступные ключу
python probe_params.py               # какие параметры принимают модели → results/probe.md
python run_experiments.py --dry-run  # план прогонов
python run_experiments.py            # прогоны → results/runs.md, runs.csv, answers/
```

Прогоны описаны в `experiments.yaml`, цены для оценки стоимости — в `prices.yaml`.

## Структура

```
bot.py               — Telegram-бот: команды, диалог, доступ
config.py            — настройки из .env
context_manager.py   — контекст диалога в памяти
api_client.py        — запросы к модели, обработка ошибок, логи
channel.py           — профиль канала → системный промпт
text_utils.py        — нарезка длинных сообщений
probe_params.py      — проба параметров моделей
run_experiments.py   — прогоны для таблицы отчёта
tests/               — pytest
```

Провайдер спрятан в `api_client.py`: чтобы перейти, например, на GigaChat, достаточно переписать этот модуль, сохранив `AIClient.complete` и `AIResult`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
```

Тесты не ходят в сеть: клиент модели подменяется фейком. Запускаются в GitHub Actions на каждый PR.

## Безопасность

- ключи только в `.env`, в коде и логах их нет;
- в логах только параметры и числа: модель, токены, время, `stop_reason`;
- бот отвечает только пользователям из `ALLOWED_USER_IDS`;
- профиль своего канала хранится в `channel.yaml` вне репозитория;
- посредник зарубежный — не отправляйте через бота персональные данные других людей.
